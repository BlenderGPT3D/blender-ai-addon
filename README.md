# AI Copilot for Blender

Add-on для Blender, который превращает вьюпорт в чат с AI-ассистентом: опишите словами или покажите картинкой, что нужно создать или изменить — аддон сгенерирует Python-код (`bpy`) и выполнит его прямо в сцене.

## Возможности

- **Чат прямо в 3D-вьюпорте** — панель в сайдбаре (N-panel), история сообщений, контекст сцены передаётся модели
- **Создание по картинке** — прикрепите изображение (файл или скриншот вьюпорта), и модель постарается воссоздать объект по нему
- **Правка модели** — «сделай крышку синей», «добавь фаски на все углы», «построй кресло как на фото»
- **Auto-run** — сгенерированный код выполняется автоматически; при ошибке лог возвращается модели, и она чинит код
- **Любой OpenAI-совместимый API** — OpenAI, OpenRouter, DeepSeek, Groq, локальные Ollama и LM Studio
- Не требует ничего устанавливать в Python Blender — используется встроенный `requests`

## Установка

### Blender 4.2+ (Extensions)
1. Скачайте `blender-ai-addon-*.zip` (Release)
2. `Edit > Preferences > Add-ons > Install` → выберите zip

### Из исходников
```bash
git clone https://github.com/BlenderGPT3D/blender-ai-addon.git
cd blender-ai-addon
```
Заархивируйте содержимое репозитория в zip (чтобы `blender_manifest.toml` был в корне архива) и установите как выше.

## Быстрый старт

1. Откройте сайдбар вьюпорта (`N`) → вкладка **AI Copilot**
2. Раскройте **AI Settings**:
   - **Base URL**: `https://api.openai.com/v1` (или ваш провайдер)
   - **API Key**: ключ из личного кабинета провайдера
   - **Model**: `gpt-4o` / любая vision-модель
3. Введите запрос и нажмите **Send**

Примеры запросов:

```
Создай низкополигональную ёлку: конус из 3 ярусов и цилиндр-ствол, материал зелёные
Прикрепи фото → «Сделай стилизованную версию этого объекта»
«Выдели все кубы и поставь их в ряд с шагом 2 метра»
```

## Поддерживаемые провайдеры

| Провайдер | Base URL |
|---|---|
| OpenAI | `https://api.openai.com/v1` |
| OpenRouter | `https://openrouter.ai/api/v1` |
| DeepSeek | `https://api.deepseek.com/v1` |
| Ollama (локально) | `http://localhost:11434/v1` |
| LM Studio (локально) | `http://localhost:1234/v1` |

Для работы с картинками модель должна поддерживать vision (например, `gpt-4o`, `claude-*` через OpenRouter, `llava` в Ollama).

## Как это работает

```
Пользователь (текст + картинка)
        │
        ▼
┌──────────────────────┐   Системный промпт: версия Blender,
│   core/ai_client.py   │──► описание сцены, правила написания bpy-кода
└──────────────────────┘
        │  POST /chat/completions (OpenAI-compatible)
        ▼
┌──────────────────────┐
│   core/executor.py   │   exec() с окружением bpy, bmesh, mathutils;
└──────────────────────┘   захват stdout и traceback
        │
        ▼
   Результат в сцене + лог выполнения обратно в чат
```

- `operators.py` — операторы: отправка (в фоновом потоке, UI не блокируется), скриншот вьюпорта, повторный запуск кода
- `panels.py` — интерфейс чата и настроек в сайдбаре
- `properties.py` — свойства сцены: история чата, настройки API
- `core/prompts.py` — сборка системного промпта с контекстом сцены
